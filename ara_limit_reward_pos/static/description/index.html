Limit Promotions by Points or Amount + Flash Sale Coupons

POS / SALE

What is the Module Function?


This module adds advanced promotion controls for Point of Sale (POS) and Sales Order by allowing you to:
  • Limit Promotion Usage, based on Order Value / Total Amount.
  • Enable Flash Sale Coupons, Create time-limited program type coupons. Coupons can be applied only within a specific date/time window.
  • Dual Channel Support, All features work on both POS and Sales Order modules

Tutorial Use Module

How To Install?

Open App => search name module "ara_limit_reward_pos" => Install

1. Setup Type Promotions

Open Discount and Loyalty => Click New or update current record => Set program type to Promotions => Set limit value => Set condition rules and reward

2. Use Sale Order (Type Promotions)

Open Sales => Create new record => Click Reward button. If reward value is more than the limit value, a pop-up notification will appear and the reward will not be added.

If the reward value is less than or equal to the limit value, the promotion can be applied. When you click Confirm, it will automatically be recorded in the promotion history.

If you click Cancel, the promotion will be automatically removed from the promotion history.

3. Use Point of Sale (Type Promotions)

Open Point of Sale => Add product => Click Payment. The system automatically checks the limit. If the reward value exceeds the limit, the reward line will be automatically removed from the order.

If the reward value is less than or equal to the limit value, choose a payment method and click Validate. The promotion will then be automatically added to the promotion history.

4. Setup Type Coupons

Open Discount and Loyalty => Click New or update current record => Set program type to Coupons => Set limit value => Set Flash Sale start and end date
=> Set condition rules and reward => Click Generate Coupons and click Generate

5. Use Sale Order (Type Coupons)

Open Sales => Create new record => Click Coupon Code button => A pop-up will appear. Input coupon code => Click Apply. If the reward value is more than the limit value, or the current date is outside the Flash Sale start and end date, a notification will appear and the reward will not be applied.

If the reward value is less than or equal to the limit value, the coupon or flash sale can be applied from the start date to the end date. When you click Confirm, the promotion will automatically be added to the promotion history.

If you click Cancel, the promotion will be automatically removed from the promotion history.

6. Use Point of Sale (Type Coupons)

Open Point of Sale => Add product => Click Actions => Click Enter Code => Input code => Click Apply

Note: Coupons and Promotions in POS share the same usage limit logic, whether based on points or order amount.
